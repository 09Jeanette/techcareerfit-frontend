# TechCareerFit — Frontend (skeleton)

This folder contains the React.js frontend skeleton for TechCareerFit.

Quick start:

1. Install dependencies

```bash
cd techcareerfit-frontend
npm install
```

2. Start dev server

```bash
npm start
```

Notes:
- Authentication endpoints are wired to `https://techcareerfit-backend.onrender.com` per the API docs in `docs/API_FOR_FRONTEND.md`.
- Logo placeholder: `public/logo-placeholder.svg`.
